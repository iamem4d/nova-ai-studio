# Nova AI Studio

A multilingual, responsive static website for Nova AI Studio.

## Languages
English (default), Arabic (RTL), French, German and Simplified Chinese.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the Pages deployment and open the URL shown in Settings → Pages.

## Before launch
- Replace `hello@example.com` in `index.html` with a public contact address you are authorized to use.
- Replace concept projects with real work as it becomes available.
- Review all translations and contact details.
- Do not publish private keys, passwords, API keys or personal information.
